
### **README.md Dosyasını GitHub’a Yükle**

Eğer önceki adımlarda projeni GitHub’a yüklediysen, `README.md` dosyasını eklemek için şu adımları takip edebilirsin:

1. **Değişiklikleri Git’e Ekle**:
   - VS Code’un “Source Control” paneline git.
   - `README.md` dosyasının listelendiğini göreceksin.
   - “+” (Stage Changes) butonuna tıkla.

2. **Commit Yap**:
   - “Source Control” panelinin üst kısmındaki metin kutusuna bir commit mesajı yaz:
     ```
     Add README.md with project details
     ```
   - “✔” (Commit) butonuna tıkla.

3. **GitHub’a Yükle**:
   - “...” (üç nokta) menüsüne tıkla ve “Push” seçeneğini seç.
   - Bu, `README.md` dosyasını GitHub’a yükleyecek.
   - Web ID: 0: *"Then push the commit to GitHub like you would with a regular commit."*

4. **GitHub’da Kontrol Et**:
   - GitHub depoya git (`https://github.com/<kullanici-adi>/monad-mcp-egg`) ve `README.md` dosyasının ana sayfada güzel bir şekilde görüntülendiğini gör.
   - Web ID: 2: *"Code hosting services such as GitHub, Bitbucket, and GitLab will also look for your README and display it along with the list of files and directories in your project."*
